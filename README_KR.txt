팬을 포함한 풍동 조립 대시보드

index.html을 Chrome 또는 Edge에서 여세요. 외부 CDN 없이 오프라인으로 동작하는 단일 HTML입니다.
완성 모습: 선택·분해 상태를 초기화하고 경계선을 숨겨 전체 외형을 확인합니다.
조각 확인: 출력 조각의 경계선을 표시합니다. 표에서 ID를 선택하면 해당 조각만 강조됩니다.
팬은 FAN001을 선택하거나 시로코팬 필터에서 찾을 수 있습니다.

흡입부 → 정류부 → 수축부 → 시험부 → 확산부 → DR-G35HSC 시로코팬 → 위로 올라가는 토출덕트
출력용 조각 271개와 구매 팬의 참고 모델 1개를 포함합니다.
기존 271개 부품의 형상 데이터는 보존하고 토출덕트 전체를 팬 공간 680 mm만큼 뒤로 옮겼습니다.
기존 90° 굴곡 덕트와 긴 수직 토출부를 그대로 유지했습니다.

팬 외형은 카탈로그의 치수를 참고해 케이싱, 원형 접속구, 임펠러, 모터, 받침을 단순화한 근사 모델입니다.
팬의 내부 구조·포트 배치·680 mm 장착 간격은 조립 모습을 보기 위한 예시이며 제작도나 실제 간섭 검증용이 아닙니다.
실제 장착 방향과 체결 위치는 실물 또는 제조사 도면을 기준으로 확인하세요.
참고 카탈로그: https://ventilation-expert.com/assets/upload/file_pdf_prod/1614582858.pdf

wind_tunnel_fan.png는 동일한 3D 형상에서 만든 전체 조립 미리보기입니다.
GUIDE에 장면/부품 선택/보기 전환 검사와 기존 부품의 형상 데이터 보존 검사 결과를 포함했습니다.
실제 브라우저의 WebGL 렌더링과 모바일 레이아웃은 이번 환경에서 직접 검증하지 못했습니다.
