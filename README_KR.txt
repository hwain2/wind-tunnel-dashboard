풍동 조립 3D 대시보드 — 도출덕트 리브 및 측면 토출 팬 반영

index.html을 Chrome 또는 Edge로 여세요. 외부 CDN 없이 동작하는 단일 HTML입니다.
완성 모습: 조립 상태의 전체 외관을 표시합니다.
조각 확인: 조각 경계선을 켜고 표에서 선택한 부품을 강조합니다. 다른 부품은 반투명해집니다.
검색, 구간 필터, 선택 부품만 보기, 분해 보기와 시점 변경을 사용할 수 있습니다.

출력 부품 271개와 구매 팬 참조 모델 FAN001 1개, 총 272개 객체입니다.
기존 221개 부품의 형상과 위치를 보존했습니다. 시험부도 추가 변경하지 않았습니다.
도출덕트 OD001~OD050에는 접합면에서 안쪽 12 mm 폭의 리브, 총 벽 두께 15 mm를 추가했습니다.
기본 벽은 5 mm이며 유로 안쪽은 보존했습니다. 일체형 돌기·홈 199쌍을 반영했습니다.
35 mm M10 체결부, Ø11 관통홀과 하류측 너트 홈 대변 17.4 mm/깊이 8.8 mm를 보존했습니다.

팬은 전면 축방향 흡입, 90° 측면 토출, 곡선 케이싱과 후면 모터를 가진 근사 모델입니다.
도출덕트는 팬 옆 토출구에 배치하고 기존 엘보를 통해 위로 올라가도록 했습니다.
팬 형상·치수·연결 위치는 조립 모습 참고용이며 실물 장착 치수의 검증 결과가 아닙니다.
팬은 출력 STL에 포함하지 않습니다. 실제 팬 체결은 실측 또는 제조사 도면으로 확인하세요.
참고 카탈로그: https://ventilation-expert.com/assets/upload/file_pdf_prod/1614582858.pdf

wind_tunnel_side_fan.png는 동일한 3D 데이터로 만든 전체 조립 미리보기입니다.
GUIDE에 형상 보존, 배치, 선택 동작, 도출덕트 접합부 검사 결과를 넣었습니다.
실제 브라우저 WebGL 렌더링과 모바일 화면은 이 환경에서 직접 확인하지 못했습니다.

GitHub Pages에는 index.html과 .nojekyll을 게시 폴더에 넣으면 됩니다.
