풍동 조립도 — 최종 대시보드

열기: ZIP 압축을 풀고 index.html을 Chrome 또는 Edge에서 여세요.
HTML 하나에 실제 형상과 3D 엔진을 포함해 인터넷 없이 작동합니다.

부품 탐색
- 왼쪽 목록에서 RC001 같은 번호를 클릭하면 해당 조각이 강조됩니다.
- 나머지 조각은 반투명하며 보기 설정에서 불투명도를 조절할 수 있습니다.
- 3D 모델의 조각도 직접 클릭할 수 있습니다.
- 구간 필터와 번호 검색은 부품 목록에 적용됩니다.
- 선택 확대, 선택 부품만 보기, 윤곽선, 조각 간격을 지원합니다.
- 조각 간격 0 mm가 원래 조립 위치입니다.
- 모바일에서는 보기 설정을 펼쳐 조절하세요.

조작: 좌클릭 드래그 회전 / 휠 확대·축소 / 우클릭 또는 Shift 드래그 이동
단축키: Esc 선택 해제 / F 선택 확대 / Home 전체 맞춤 / 위아래 화살표 부품 이동

형상: 흡입부 32 + 정류부 123 + 수축부 39 + 확산부 15 = 출력 부품 209개
시험부 TS001은 분할하지 않은 원본 기준 형상으로 함께 표시합니다.
기존 STL 형상, 부품 번호, 출력기 배정, 조립 좌표는 그대로 유지했습니다.

GitHub Pages에 올리기
1. GitHub에 Public 저장소를 만듭니다. 예: wind-tunnel-dashboard
2. ZIP을 풀고 index.html, .nojekyll, README_KR.txt를 저장소 최상위에 업로드합니다.
   ZIP 파일 자체를 업로드하면 홈페이지로 열리지 않습니다.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save
4. 배포가 완료되면 GitHub가 표시하는 .github.io 주소로 공유할 수 있습니다.

Three.js r160 MIT 라이선스는 index.html 안에 포함되어 있습니다.
